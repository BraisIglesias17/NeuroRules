Generate 3D graph

A 3D chart is a graphical representation of data in three dimensions, adding depth to the traditional 2D chart by incorporating the z-axis.

In order to display a 3D graph you have to follow the next steps

  • Select 3D Graph in the Type options.
  • Select from the X Axis list the variable that you want to represent in the X axis
  • Select from the Z Axis list the variable that you want to represent in the Z axis
  • Select from the Left Y Axis list the variable that you want to represent in the Y axis
  • Press Plot

Requirements: The same variable can not be chosen for various axis.
