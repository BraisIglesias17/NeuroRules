Rule generating task

This kind of task trains a neurofuzzy or neuroclassifier network with your data. The aim is to obtain human readable rules from the data. For each output, a combination of submodels given by the inputs is trained. Each submodel has its own performance metrics and rules generated.

In order use a rule generating model follow the next steps:

  • Select which variables will be the inputs.
  • Select which variables will be the outputs, a neurofuzzy or neuroclassifier system will be generated for each of them.
  • Select the options desired for the neural network, they can be seen in the following tables..
  • Name the task
  • Check on the report if the task is the desired and press train or train background if wanted.
