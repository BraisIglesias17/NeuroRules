Fitted Regression Line

A fit regression line is a straight line used in linear regression to model the relationship between two variables, often showing the trend or correlation between them.

In order to display a fitted regression line graph you have to follow the next steps

  • Select the 2D graph in the Type options.
  • Check the Show fitted regression line option.
  • Select from the X Axis list the variable that you want to use as predictor in the regression.
  • Select from the Left Y Axis list the variable that you want to use as predicted in the regression.
  • Press Plot.
Interpretation:

The regression line aims to minimize the difference between the observed values of the dependent variable and the values predicted by the line. In other words, it represents the "best fit" to the data points in terms of minimizing the overall error.

R-squared (R2) is a statistical measure that represents the proportion of the variance in the dependent variable that is explained by the independent variables in a regression model. The closer to 1 is the R2 the best the model adjust to the data.
