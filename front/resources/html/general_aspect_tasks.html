What is a Task?

A task is what we call to a procedure that allows you to obtain either a trained model from your data. This model can have different aims, from only predicting new data and observing the metrics behaviour to obtain human readable rules to extract knowledge from the data. That difference is explained in the next sections as "Prediction model" and "Rule". You can save a task to load it and analyze it later.

Task Info

Each task must have a name so that you can easily indentify it, the name must only contain alphanumeric characters and '_', other charcaters are not allowed. Apart from that, the task has a reference to the data it uses so it is never lost and once you load a task you also load the data attached to it, this allows to keep track of the tasks and help the analysis by allowing you to use the other functionalities of the program. Task Process

When you start a task, the first step is to select the variables tha will be used as input and output of the models. Once this is accomplished you have to select the machine learning alogithms that you want to apply for each output and the validation method. After verifying that you have selected what you wanted, you can start the training, where you have two options.

  • Foreground training: this is the default option and means that once you start the training process, a progress bar will be displayed and will blocked the program use so you will have to wait until it finishes to continue. This is meant to small tasks were the training time is not extremely large.
  • Background training: in this case, the program will hide and perform the training in backgorund and will notify the user when it has finished and where the file was stored. With this option when training is accomplished, the program automaticaly shuts down. It is meant to large tasks were the training time may be large.
