Generate 2D graph

A 2D chart is a graphical representation of data in two dimensions, typically using x and y axes to display data points.

In order to display a 2D graph you have to follow the next steps

  • Select 2D Graph in the Type options.
  • Select from the X Axis list the variable that you want to represent in the X axis
  • Repeat the previous step for Left Y Axis and Right Y Axis (either one or both)
  • Press Plot

Requirements: The same variable can not be chosen for various axis.
