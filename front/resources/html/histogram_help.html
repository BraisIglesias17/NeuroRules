Histogram

A histogram is a graphical representation that displays the distribution of a dataset, usually depicting data frequencies in different bins or intervals. The program allows you to specify the number of bins in which you want to group your data.

In order to display a histogram graph you have to follow the next steps

  • Select Historgam in the Type options.
  • Select from the X Axis list the variable that you want to get the histogram from.
  • Press Plot.
Options:
  • Number of bins: indicates the number of bins (bars) in which the variable will be grouped and displayed. 10 bins is set by default. The number of bins can not be negative or greater than the number of samples.
